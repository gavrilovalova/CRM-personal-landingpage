# Раскладка блоков: мобильная (390) → десктоп (1440)

Точные значения смотри в `reference/mobile.html` и `reference/desktop.html`. Здесь структура и поведение.

## 0. Шапка
- **Моб.:** высота 44, слева логотип (квадрат 36, r12) + `[Название]` 17/700, справа ghost-кнопка «Открыть».
- **Деск.:** высота 56, логотип 44 (r14) + название 20/700. Справа `<nav>`: три якоря 16/500 цвета `ink`, gap 28, затем ghost-кнопка h48. Шапка не липкая.

## 1. Первый экран
- **Моб.:** одна колонка, gap 26: шапка → H1 + лид (gap 16) → кнопка на всю ширину + подпись по центру (gap 10) → карточка Ани (фон `surface`, r28, p20) со стикером, вылезающим за верхний правый угол (`-top-3.5 right-1.5`). Поля секции: 16 сверху, 48 снизу.
- **Деск.:** шапка, отступ 64, дальше две колонки `flex-wrap`, gap 56, по центру по вертикали. Слева (≈ 1fr, min 520) H1, лид (max-w 560), ряд «кнопка + подпись» в строку. Справа (≈ 1fr, min 420) карточка Ани (r36, p28) с двумя заметками и двумя стикерами: лаймовый сверху справа, розовый снизу слева (`-bottom-5 -left-4`). Нижнее поле 96.

## 2. Знакомо?
- Фон `surface`, верхние углы скруглены (36 / 56).
- **Моб.:** метка → H2 → 3 белые карточки столбиком (gap 12, r24, p20) → вывод 20/700.
- **Деск.:** метка + H2 (max-w 820), три карточки в ряд (gap 16, r28, p28), вывод (max-w 900).

## 3. Решение
- Фон `brand`, текст белый, верх скруглён, `margin-top` −36 / −56 (наезжает на серую секцию).
- **Моб.:** метка → H2 → текст → белая карточка Димы (наклон −1.5°).
- **Деск.:** две колонки. Слева метка, H2, текст 20px. Справа карточка Димы (r36, p28, наклон −2°, три заметки).

## 4. Как это работает (`id="how"`)
- Фон белый, верх скруглён, `margin-top` −56 только на десктопе (наезжает на синюю секцию). На мобильном просто белый фон без наезда, поле сверху 64.
- **Моб.:** `<ol>` столбиком. Каждый шаг — серая карточка, внутри строка: цветной квадрат 44 с цифрой и текст.
- **Деск.:** три карточки в ряд. Квадрат 56 сверху, под ним заголовок 22 и текст 17.

## 5. Что умеет (`id="features"`)
- **Моб.:** сетка 2×3, gap 10. Плитки r22, p16, иконка 28, заголовок 16/700, текст 14.
- **Деск.:** 3×2, gap 16. Плитки r28, p28, иконка 36, заголовок 21, текст 17.
- Цвета плиток по порядку: синяя, серая, серая, розовая, лаймовая, серая.

## 6. Чего здесь нет
- Фон `ink`, текст белый, верх скруглён.
- Метка белая с тёмным текстом, H2 с лаймовыми «своих людей».
- `<ul>`: пункты с рамкой `line-dark` (r20 / r22), розовый кружок 32 / 36 с крестиком.
- **Деск.:** одна колонка, список `max-w-[760px]`. Нижнее поле 136, чтобы следующая белая секция наехала скруглением.

## 7. Для кого
- Фон белый, верх скруглён, `margin-top` −36 / −56 (наезжает на тёмную секцию).
- **Моб.:** три серые карточки столбиком, внутри строка: иконка 28 слева, текст 16 справа.
- **Деск.:** три карточки в ряд, иконка 36 сверху, текст 18 под ней.

## 8. Вопросы (`id="faq"`)
- Карточки: белые с рамкой 2px `surface`, r24 / r28, вопрос `<h3>`, ответ цвета `muted`.
- **Моб.:** вместо крупного заголовка серая метка «Вопросы». Сделай её `<h2>`, стилизованным под метку, чтобы у секции был заголовок. Под ней 4 карточки столбиком.
- **Деск.:** две колонки. Слева крупный `<h2>` «Вопросы» (min 280), справа сетка 2×2 из карточек.

## 9. Финальный призыв + подвал
- **Моб.:** синяя плашка (r32, p 32/22/24) со стикером над правым верхним углом, H2, текст, белая кнопка на всю ширину. Ниже подвал: `[Название]` слева, ссылка «Открыть приложение» справа, 14px.
- **Деск.:** плашка r48, p 72/64. Внутри строка `flex-wrap`: слева H2 + текст (max-w 560), справа белая кнопка h68. Подвал 16px.

## Поведение
- Без JS. Анимации не обязательны. Если нужны, только лёгкий hover у кнопок и карточек (`transition-colors`).
- Наклоны не должны вызывать горизонтальный скролл: у корня `overflow-x: clip` (или у секций).
