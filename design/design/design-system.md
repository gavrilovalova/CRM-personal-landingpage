# Дизайн-система (вариант A «Электрик»)

Настроение: яркая, дружелюбная, «стикерная». Белый фон, электрический синий как основной цвет, лайм и розовый как акценты, крупные скругления, жирный гротеск, лёгкие наклоны у стикеров и карточек.

## Цвета

| Токен (Tailwind) | HEX | Где используется |
|---|---|---|
| `brand` | `#2E5CFF` | Главные кнопки, плашка «людей,», фон секции «Решение» и финального призыва, иконки на сером |
| `brand-hover` | `#1A3FD6` | hover у кнопок и ссылок |
| `ink` | `#0F0F14` | Основной текст, фон секции «Чего здесь нет» |
| `surface` | `#F2F4F8` | Фон секции «Знакомо?», серые карточки, ghost-кнопка, рамка карточек FAQ |
| `lime` | `#C6F432` | Стикеры, метки, акцентные плитки, выделение текста |
| `pink` | `#FFB8E0` | Метки, аватар, плитка «Правка», кружки с крестиком |
| `muted` | `#4A4D57` | Подзаголовки и описания на белом и сером |
| `subtle` | `#5B5F6B` | Подписи, даты в старых заметках, подвал |
| `on-brand-muted` | `#E3E9FF` | Второстепенный текст на синем |
| `line-dark` | `#2E3038` | Рамки пунктов на тёмном фоне |
| `on-pink` | `#2A2230` | Описание на розовой плитке |
| `on-lime` | `#262B12` | Описание на лаймовой плитке |

Контраст проверен: белый на `brand` ≈ 5.3:1, `muted` на белом ≈ 8:1, `subtle` на `surface` > 5:1.

## Отступы

- Боковые поля: 20px на мобильном, 40px на десктопе. Контейнер `max-width: 1280px`.
- Вертикальные поля секции: 56px на мобильном, 104–120px на десктопе.
- Между меткой, H2 и контентом: 24px на мобильном, 20px (метка → H2) и 40px (H2 → контент) на десктопе.
- Между карточками: 10–12px на мобильном, 16px на десктопе.
- Внутренние поля карточки: 20px на мобильном, 28px на десктопе.

## Компоненты

**Button**: всегда `<a>`.
- `primary`: фон `brand`, белый текст, h 60 / 64px. На мобильном на всю ширину, на десктопе ширина по контенту, `px-9`.
- `white`: белый фон, текст `brand` (в финальном призыве).
- `ghost`: фон `surface`, текст `ink`, h 44 / 48px («Открыть» в шапке).
- hover: `brand` → `brand-hover`, у white и ghost лёгкое затемнение. Стрелка «→» входит в текст.

**Chip** (метка секции): `inline-flex self-start`, `px-3.5 py-2` (десктоп `px-4 py-[9px]`), `rounded-full`, 14/15px, 700. Цвет фона задаётся пропсом: pink / lime / surface / white / lime-on-blue.

**Sticker**: как Chip, но `absolute` и с наклоном (`rotate-[5deg]`, `-rotate-[4deg]`), 13/15px.

**ContactCard**: аватар-круг с инициалами (52 / 64px), имя 18 / 22px 700, строка «откуда знакомы», чипы-каналы (белые, если карточка на сером), заметки (дата 12–13px 700: свежая `brand`, старые `subtle`; текст 15–17px). Старые заметки с `opacity: 0.6`.

**Card / Tile**: фон `surface` (или акцентный), радиус 24 / 28px, иконка 28 / 36px цвета `brand` (на акцентном фоне цвета `ink`).

**Icon**: SVG 24×24, `stroke="currentColor"`, `stroke-width` 2–2.2, скругления `round`. Файлы лежат в `icons/`.

## Брейкпоинты

- База: мобильная раскладка.
- `md` (768px): сетки карточек по 2 в ряд.
- `lg` (1024px): десктопная раскладка (hero и «Решение» в 2 колонки, карточки по 3, «Что умеет» 3×2, FAQ 2×2 с заголовком слева, финал в строку).
