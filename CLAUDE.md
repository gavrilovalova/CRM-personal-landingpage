## Проект

- Лендинг личной CRM: одна страница, одно целевое действие - перейти в приложение
- Приложение - отдельный репозиторий, адрес `https://relma-app.netlify.app`
- Макет - `design/`: HTML-файлы - образец вида, `design/README.md` - токены, экраны, тексты. Стек и правила - из этого файла, при расхождении прав он

## Стек

- Astro, Tailwind CSS 4; статичная страница, без сервера и базы
- Цвета, шрифты и отступы - только через файл дизайн-токенов `src/styles/tokens.css`
- pnpm, `pnpm-lock.yaml` в git
- Новую библиотеку или сервис - обсуждай со мной

## Выкатка

- Хостинг - Netlify, проект `relma-landing`, адрес `https://relma-landing.netlify.app`
- Push в main → Netlify сам собирает (`pnpm build`) и выкладывает папку `dist` → главная отвечает 200
- Переменные сборки (`PUBLIC_APP_URL`, `NODE_VERSION`) - в настройках проекта в Netlify, не в репозитории
- Без стенда и отката: сломалось - правим и катим новую версию
- Сначала нужен был другой вариант: GitHub Actions собирает `dist/` → `rsync` на свой сервер → nginx. Он не получился, поэтому всё выкатываем через Netlify
