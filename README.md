# Лендинг личной CRM

Одна статичная страница. Все кнопки ведут в приложение.

## Как запустить у себя

1. Установить зависимости: `pnpm install`
2. Запустить с автообновлением при правках: `pnpm dev` и открыть http://localhost:4321
3. Собрать готовые файлы сайта: `pnpm build` — результат в папке `dist/`
4. Посмотреть собранную версию: `pnpm preview` и открыть http://localhost:4321. Остановить: `pnpm astro preview stop`

## Адрес приложения

Адрес берётся из переменной `PUBLIC_APP_URL` во время сборки.

- Локально: добавить в файл `.env` строку `PUBLIC_APP_URL=https://app.<домен>`
- Пока переменной нет, кнопки ведут на заглушку `https://app.example.com`
- Если в адресе ошибка (например, нет `https://`), сборка остановится и скажет об этом

## Где что лежит

- `src/content/landing.ts` — все тексты страницы
- `src/styles/tokens.css` — дизайн-токены: цвета, шрифты, размеры, скругления
- `src/components/sections/` — блоки страницы по порядку сверху вниз
- `src/components/ui/` — кнопка, метка, стикер, иконки, карточка контакта
- `src/assets/fonts/` — шрифт Onest (лицензия OFL, файл `OFL.txt` рядом)
- `design/` — макет: тексты, токены, эталонные HTML и скриншоты
